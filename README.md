## What ChatGuardian Does

ChatGuardian gives Telegram group owners and moderators a way to keep discussions on topic by detecting spam, questionable promotions, and scam-oriented messages as they arrive. Its workflow is intended for active communities where moderation decisions need to happen quickly.

The bot is designed with transparent moderation and privacy-first operation in mind, helping teams maintain clearer control over how policies are enforced. Multi-language support and adaptive learning also make it suitable for communities with varied audiences and changing communication patterns.

- Analyze messages in real time during Telegram conversations
- Filter spam and reduce repetitive or unwanted submissions

- Adapt to changing message patterns through learning
- Apply community-defined policies with a custom rule engine
- Make moderation behavior easier to understand and review

A standard setup looks like this:

1. Add ChatGuardian to the Telegram group or community where it will moderate.

3. Allow the bot to inspect incoming messages in real time.
4. Check flagged messages and refine the rules when necessary.

For example, you can:

- Configure language handling for the intended audience
- Review moderation results and adjust behavior over time
